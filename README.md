# VEC Reliability Lab

Twenty synthetic, runnable reliability lessons in 15 language editions. **300 reading resources share twenty experiments. They are not 300 independent software implementations, and award acceptance is not assured.**

Independent community teaching material. No official affiliation or endorsement. All experiments use invented data; none computes a hidden score or uses challenge datasets.

## Start

Python 3.10+ and NumPy are required. Clone this repository, create a virtual environment and install `requirements.txt`. Run `python3 tools/experiments.py --lesson 01 --seed 7`. Full setup instructions, a worked reference output and an interpretation appear in each edition.
