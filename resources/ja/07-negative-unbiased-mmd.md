# 不偏 MMD 推定値が負になる理由

**日本語 · Reliability Lab 07 · 信頼性を学ぶ実験と解説**

この教材は合成データを使い、単一細胞・空間予測のモデル化や評価における問題を一つずつ説明します。大会データを読み込まず、公式スコアや隠された試料の結果も予測しません。公式教材ではありません。

母集団の二乗カーネル距離は非負です。しかし不偏推定量は対角項を除くため、小標本では負になり得ます。有偏推定量はその項を含みます。

## 実験を実行する

新しい環境を作り、リポジトリをクローンして指定の依存関係を導入してください。コマンドはリポジトリ直下で実行します。まず変更前の出力を読み、次に条件を変えます。コマンドと JSON のキーは各言語で共通のコード識別子です。

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 07 --seed 7
```

## 問い

二つの推定値の符号が違う理由は何ですか。

## 参照出力：乱数シード 7

```json
{
  "unbiased_mmd_squared": -0.8617044036602768,
  "biased_mmd_squared": 0.0029603131031104013,
  "population_distance_nonnegative": true
}
```

## 結果の読み方

対角補正が有限標本の値を変えます。負の推定値は母集団距離が負であることを意味しません。

## 追加の実験

カーネルを固定し、二番目の標本を遠ざけてください。
