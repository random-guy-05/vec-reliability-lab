# 正規化と時間的な混合は交換できない

**日本語 · Reliability Lab 05 · 信頼性を学ぶ実験と解説**

この教材は合成データを使い、単一細胞・空間予測のモデル化や評価における問題を一つずつ説明します。大会データを読み込まず、公式スコアや隠された試料の結果も予測しません。公式教材ではありません。

カウントを混合してから正規化することと、正規化済み対数発現を平均することは異なります。総数と log1p が非線形性を生みます。

## 実験を実行する

新しい環境を作り、リポジトリをクローンして指定の依存関係を導入してください。コマンドはリポジトリ直下で実行します。まず変更前の出力を読み、次に条件を変えます。コマンドと JSON のキーは各言語で共通のコード識別子です。

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 05 --seed 7
```

## 問い

重み 0.5 の二つの中点が違う理由は何ですか。

## 参照出力：乱数シード 7

```json
{
  "normalize_after_mix": [
    9.115140186122302,
    6.813544494621113
  ],
  "mix_after_normalize": [
    4.6052201834882585,
    4.6052201834882585
  ],
  "difference": 5.0215609817365605
}
```

## 結果の読み方

[10,0] と [0,1] は総数が違います。先の正規化は深度差を消し、対数の平均は別の非線形性を加えます。

## 追加の実験

両行の総数を同じにして比較してください。
