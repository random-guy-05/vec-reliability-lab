# 細胞分割では全ての生物試料が共有され得る

**日本語 · Reliability Lab 15 · 信頼性を学ぶ実験と解説**

この教材は合成データを使い、単一細胞・空間予測のモデル化や評価における問題を一つずつ説明します。大会データを読み込まず、公式スコアや隠された試料の結果も予測しません。公式教材ではありません。

細胞の無作為分割は同じ胚の細胞を学習とテスト双方に入れます。行は違っても、試料特有の効果は共有されたままです。

## 実験を実行する

新しい環境を作り、リポジトリをクローンして指定の依存関係を導入してください。コマンドはリポジトリ直下で実行します。まず変更前の出力を読み、次に条件を変えます。コマンドと JSON のキーは各言語で共通のコード識別子です。

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 15 --seed 7
```

## 問い

両側に現れる試料 ID は何個ですか。

## 参照出力：乱数シード 7

```json
{
  "cell_split_shared_specimens": 6,
  "specimen_split_shared_specimens": 0,
  "total_specimens": 6
}
```

## 結果の読み方

細胞分割は試料を共有します。明示的な群分割では共有しません。多数の細胞は多数の独立した胚ではありません。

## 追加の実験

同じ胚に二つの別名を与え、見逃す依存を考えてください。

## 限界

この例が示すのは数値的な仕組みです。実データでの重要性や因果関係を証明せず、公式評価器の代わりにもなりません。仮定、出典、元データを保存し、利用可能なデータで検証してください。
