# 意味上の等しさとメモリ配置は別の確認事項

**日本語 · Reliability Lab 18 · 信頼性を学ぶ実験と解説**

この教材は合成データを使い、単一細胞・空間予測のモデル化や評価における問題を一つずつ説明します。大会データを読み込まず、公式スコアや隠された試料の結果も予測しません。公式教材ではありません。

同じ値の行列でもメモリの順序は異なり得ます。型と連続順序を正規化すれば、配置に依存しないダイジェストを計算できます。

## 実験を実行する

新しい環境を作り、リポジトリをクローンして指定の依存関係を導入してください。コマンドはリポジトリ直下で実行します。まず変更前の出力を読み、次に条件を変えます。コマンドと JSON のキーは各言語で共通のコード識別子です。

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 18 --seed 7
```

## 問い

正規化したハッシュが一致する理由は何ですか。

## 参照出力：乱数シード 7

```json
{
  "c_layout": true,
  "f_layout": true,
  "semantic_digest_equal": true,
  "warning": "A real semantic hash must also include shape, gene order, cell order and coordinates."
}
```

## 結果の読み方

両行列を同じ型と順序へ変えるからです。完全なハッシュには形状、遺伝子順、細胞順、座標も必要です。

## 追加の実験

遺伝子列を交換し、必要なメタデータを考えてください。
