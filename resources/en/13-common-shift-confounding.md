# A common cross-type shift is not automatically technical

**English · Reliability Lab 13 · Worked reliability exercise**

This is a small, synthetic experiment for participants who build single-cell or spatial predictions. It explains a modeling or evaluation failure without reading challenge data. It is an independent teaching resource, not an official scorer or a prediction of a leaderboard score.

A median shift across cell types can separate a shared component from type-specific residuals algebraically. Calling the shared component a technical batch effect requires an additional assumption: broad biological regulation can also be shared. The decomposition alone cannot identify its cause.

## Run the exercise

Use a fresh environment. Clone the repository, install the stated dependency, and run this lesson from the repository root. Read the output before changing anything. The JSON keys are literal code identifiers shared across language editions.

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 13 --seed 7
```

## Interpret the result

In the constructed example the median recovers the component deliberately named technical. Replacing that label with a common biological response leaves the observed numbers unchanged. The numerical recovery is valid; the causal label needs outside evidence.

## Try another case

Add the same biological effect to all types. Check whether the median-based procedure can distinguish it from a batch effect.

## Limits

Removing a shared shift may remove genuine biology. Use matched controls, replication or an explicit model when making a technical interpretation.
