# Due leggi di crescita danno due punti medi

**Italiano · Reliability Lab 11 · Esercizio di affidabilità con soluzione**

Questo esercizio usa dati sintetici per spiegare un problema di modellazione o valutazione di previsioni unicellulari e spaziali. Non legge dati della competizione, non calcola punteggi ufficiali e non prevede risultati su campioni nascosti.

Interpolare il raggio o il suo logaritmo adatta gli stessi estremi, ma produce dimensioni intermedie differenti. Due estremi non identificano la legge di crescita.

## Eseguire l'esempio

Create un ambiente nuovo, clonate il repository e installate la dipendenza indicata. Eseguite il comando dalla radice del repository. Leggete prima il risultato senza modificare il codice. Comandi e chiavi JSON sono identificatori letterali condivisi dalle edizioni.

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 11 --seed 7
```

## Domanda

Quale punto medio si ottiene tra 100 e 400?

## Risultato di riferimento: seme 7

```json
{
  "early_radius": 100.0,
  "late_radius": 400.0,
  "linear_midpoint": 250.0,
  "constant_log_growth_midpoint": 200.0
}
```

## Interpretazione

L'interpolazione lineare dà 250. La crescita logaritmica costante dà la media geometrica 200; ogni risultato dipende dall'ipotesi.
