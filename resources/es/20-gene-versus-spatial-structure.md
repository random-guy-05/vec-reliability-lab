# La estructura entre genes difiere de la estructura espacial

**Español · Reliability Lab 20 · Ejercicio de fiabilidad con solución**

Este ejercicio utiliza datos sintéticos para estudiar un fallo concreto del modelado o de la evaluación de datos unicelulares y espaciales. No necesita datos del concurso, no calcula una puntuación oficial y no predice resultados de muestras ocultas.

Permutar filas completas conserva ciertos resúmenes entre genes. Con las posiciones fijas, esa permutación cambia qué estados de expresión son vecinos. Una estructura no demuestra la otra.

## Interpretación

La media de diferencias entre genes solo se reordena. La distancia entre filas consecutivas cambia generalmente; aquí representan vecinos en una línea fija.
