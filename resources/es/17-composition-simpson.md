# Todos los tipos pueden aumentar mientras baja la media global

**Español · Reliability Lab 17 · Ejercicio de fiabilidad con solución**

Este ejercicio utiliza datos sintéticos para estudiar un fallo concreto del modelado o de la evaluación de datos unicelulares y espaciales. No necesita datos del concurso, no calcula una puntuación oficial y no predice resultados de muestras ocultas.

La media agregada combina expresión por tipo y composición. Un cambio hacia tipos de menor expresión puede superar el aumento dentro de cada tipo e invertir la dirección agregada.

## Interpretación

La mezcla pasa de predominio de células de alta expresión a predominio de células de baja expresión. El cambio de composición domina.
