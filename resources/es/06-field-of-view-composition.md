# Una fracción mayor no implica crecimiento de la población

**Español · Reliability Lab 06 · Ejercicio de fiabilidad con solución**

Este ejercicio utiliza datos sintéticos para estudiar un fallo concreto del modelado o de la evaluación de datos unicelulares y espaciales. No necesita datos del concurso, no calcula una puntuación oficial y no predice resultados de muestras ocultas.

Las proporciones observadas dependen del campo de visión. Retirar muchas células de un tipo aumenta la fracción de otro tipo aunque su número no cambie. Muestreo y desarrollo pueden producir cambios parecidos.

## Ejecutar el ejemplo

Cree un entorno nuevo, clone el repositorio e instale la dependencia indicada. Ejecute el comando desde la raíz del repositorio. Lea primero el resultado sin modificar el código. Las claves JSON y los comandos son identificadores literales compartidos por todas las ediciones.

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git

# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate

```

## Pregunta

¿Creció la segunda población?

## Interpretación

No: sigue teniendo 100 células. La primera pasa de 900 a 90 observaciones, por lo que aumenta la fracción de la segunda.
