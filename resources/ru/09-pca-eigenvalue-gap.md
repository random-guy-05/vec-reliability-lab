# Близкие собственные значения делают оси PCA неустойчивыми

**Русский · Reliability Lab 09 · Практикум по надежности с разбором**

Упражнение на синтетических данных объясняет одну проблему моделирования или оценки предсказаний для отдельных клеток и пространственных данных. Оно не читает данные конкурса, не вычисляет официальный балл и не предсказывает результаты скрытых образцов.

При повторяющихся собственных значениях отдельные оси внутри подпространства не уникальны. Малое возмущение ковариации может сильно повернуть ось при почти неизменной матрице.

## Запустить пример

Создайте новое окружение, клонируйте репозиторий и установите указанную зависимость. Выполните команду из корня репозитория. Сначала изучите вывод неизмененного кода. Команды и ключи JSON — общие для всех изданий идентификаторы кода.

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 09 --seed 7
```

## Вопрос

Откуда берется поворот примерно на 45 градусов?

## Разбор результата

Два наибольших собственных значения равны. Возмущение выбирает другой допустимый базис в той же плоскости.

## Дополнительный опыт

Замените одно главное собственное значение на 1.2 и сравните угол.
