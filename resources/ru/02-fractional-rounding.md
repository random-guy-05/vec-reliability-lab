# Стохастическое округление дробных отсчетов

**Русский · Reliability Lab 02 · Практикум по надежности с разбором**

Упражнение на синтетических данных объясняет одну проблему моделирования или оценки предсказаний для отдельных клеток и пространственных данных. Оно не читает данные конкурса, не вычисляет официальный балл и не предсказывает результаты скрытых образцов.

Округление вниз систематически уменьшает среднее. Добавление испытания Бернулли для дробной части сохраняет математическое ожидание, но отдельные результаты случайны.

## Запустить пример

Создайте новое окружение, клонируйте репозиторий и установите указанную зависимость. Выполните команду из корня репозитория. Сначала изучите вывод неизмененного кода. Команды и ключи JSON — общие для всех изданий идентификаторы кода.

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 02 --seed 7
```

## Разбор результата

Округление вниз дает 0,0,1,3. Среднее многих случайных округлений приближается к 0.2,0.7,1.4,3.8.

## Дополнительный опыт

Уменьшите число повторов со 100000 до 100 и меняйте seed.

## Ограничения

Пример выделяет численный механизм. Он не доказывает его значимость в реальных данных, не устанавливает причинность и не заменяет официальный оценщик. Сохраняйте допущения, происхождение и исходные данные.
