# Выравнивание вращением требует ограничения определителя

**Русский · Reliability Lab 10 · Практикум по надежности с разбором**

Упражнение на синтетических данных объясняет одну проблему моделирования или оценки предсказаний для отдельных клеток и пространственных данных. Оно не читает данные конкурса, не вычисляет официальный балл и не предсказывает результаты скрытых образцов.

Свободная ортогональная подгонка может использовать отражение. Собственное вращение имеет определитель +1 и сохраняет ориентацию; это ограничивает множество решений.

## Запустить пример

Создайте новое окружение, клонируйте репозиторий и установите указанную зависимость. Выполните команду из корня репозитория. Сначала изучите вывод неизмененного кода. Команды и ключи JSON — общие для всех изданий идентификаторы кода.

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 10 --seed 7
```

## Вопрос

Почему идеальная подгонка имеет определитель -1?

## Эталонный вывод: seed 7


## Разбор результата

Цель отражает одну координату источника. Отражение совпадает точно; собственное вращение оставляет остаточную ошибку.

## Дополнительный опыт

Создайте цель известным собственным вращением.
