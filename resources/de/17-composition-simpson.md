# Jeder Zelltyp kann steigen, während das Gesamtmittel fällt

**Deutsch · Reliability Lab 17 · Zuverlässigkeitsexperiment mit Lösung**

Dieses Experiment erklärt anhand synthetischer Daten ein Problem bei der Modellierung oder Bewertung von Einzelzell- und räumlichen Vorhersagen. Es liest keine Wettbewerbsdaten, berechnet keinen offiziellen Score und sagt keine Ergebnisse verborgener Proben voraus.

Das Gesamtmittel hängt von Expression je Typ und Mischung ab. Mehr niedrig exprimierende Zellen können den Gesamteffekt umkehren, obwohl jeder Typ steigt.

## Beispiel ausführen

Erstellen Sie eine neue Umgebung, klonen Sie das Repository und installieren Sie die angegebene Abhängigkeit. Führen Sie den Befehl im Hauptverzeichnis aus. Lesen Sie zuerst die unveränderte Ausgabe. Befehle und JSON-Schlüssel sind in allen Sprachausgaben dieselben Code-Bezeichner.

```sh
git clone https://github.com/random-guy-05/vec-reliability-lab.git
cd vec-reliability-lab
python3 -m venv .venv
# macOS/Linux; Windows: .venv\Scripts\activate
. .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 tools/experiments.py --lesson 17 --seed 7
```

## Frage

Warum fällt das Gesamtmittel trotz beider Anstiege?

## Referenzausgabe: Seed 7

```json
{
  "type_means_before": [
    1.0,
    8.0
  ],
  "type_means_after": [
    2.0,
    9.0
  ],
  "aggregate_before": 7.3,
  "aggregate_after": 2.7
}
```

## Auswertung

Die Mischung verschiebt sich zu niedrig exprimierenden Zellen. Dieser Kompositionseffekt überwiegt die Änderungen innerhalb der Typen.
